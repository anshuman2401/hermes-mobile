# Security reports

Please report suspected vulnerabilities privately. Do not include exploit details, credentials, private host addresses, session data, or owner content in a public issue or pull request. Use synthetic examples where possible.

When this repository is public and GitHub private vulnerability reporting is enabled, open **Security → Advisories → Report a vulnerability** on the [repository security page](https://github.com/anshuman2401/hermes-mobile/security). Include the affected version or commit, impact, and steps to reproduce with synthetic data.

If **Report a vulnerability** is unavailable, open a public issue asking the maintainer for a private reporting channel **without including vulnerability details**. Wait for a private channel before sending the report. Repository maintainers with security access can instead create a draft advisory.

This policy does not commit to a response time or a fixed support window.
