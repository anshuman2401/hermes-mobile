# Documentation guide

Start with the [contributor rules](../AGENTS.md), [current architecture](architecture/current-system.md), [verification runbook](testing/verification.md), and [QA matrix](testing/android-qa-matrix.md). The [toolchain reference](build/toolchain.md) lists build prerequisites.

This repository contains the Android source and a small contributor reading set. The private development repository holds dated plans, decisions, reviews, build records, screenshots, and task evidence. Source, tests, and current verifier reports establish implemented behavior; documentation alone does not certify a device, host, or release.
