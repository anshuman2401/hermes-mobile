# Code of Conduct

This project adopts the [Contributor Covenant 3.0 Code of Conduct](https://www.contributor-covenant.org/version/3/0/code_of_conduct/). It applies to participation in this repository's issues, pull requests, reviews, and other project community spaces. Please read the linked code for its full standards of behavior.

Treat other participants with respect, discuss ideas constructively, honor requests to stop unwanted interaction, protect private information, and credit others' work. Harassment, personal attacks, discrimination, threats, and disclosure of another person's private information are unacceptable.

## Reporting

To report a possible conduct violation, open an issue asking the maintainer for a private reporting channel **without describing the incident publicly**. Send the details only after a private channel has been provided. For abusive content on GitHub, you can also use GitHub's **Report content** action to report it to GitHub Support.

The repository owner reviews reports and decides appropriate action, which may include a warning, limiting participation, or removing access. Reports involving the owner should be sent to GitHub Support through its reporting tools.
